# Zala Schedule Controls & XER Reader website

This repository contains only the public download page and Windows installer. It does not contain the private desktop-app source code.

## Render deployment

Render reads `render.yaml` and publishes this folder as a static site. No build step is required.

## Local preview

Open `index.html` in a browser or serve this folder with a static file server.

## Installer

`downloads/ZalaScheduleControls-XER-Reader-Setup-1.0.6.exe`
